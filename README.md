# 🏛️ Civic Pulse

> A modern platform designed to empower citizens to report local civic issues, track resolution progress in real time, and bridge the gap between communities and local authorities.

---

## 🌐 Live Demo
* **Live Application:** [https://civic-pulse.vercel.app](file:///D:/HACKATHONS/civicpulse-backend/final.html)

---

## 🚀 Key Features

* **Issue Reporting:** Easily submit reports for local infrastructure problems (potholes, streetlights, garbage management, etc.) with category tags and descriptions.
* **Status Tracking:** Follow your submitted reports through their lifecycle from initial reporting to resolution.
* **Community Feed:** View and interact with reports submitted by other community members.
* **Responsive Design:** Optimized layout for seamless use across mobile phones, tablets, and desktop computers.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript / React
* **Styling:** Tailwind CSS
* **Hosting & Deployment:** Vercel
