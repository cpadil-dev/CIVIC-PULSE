# 🏛️ Civic Pulse

> A modern civic engagement platform that allows citizens to report, track, and monitor local community and infrastructure issues.

Civic Pulse is designed to make it easier for citizens to report problems in their local area and keep track of their progress. The platform provides a simple interface for submitting civic complaints, viewing reported issues, and monitoring their status.

---

## 📌 Project Overview

Civic Pulse is a community-focused civic issue reporting system.

The application can be used to report issues such as:

- 🛣️ Road and pothole problems
- 💡 Streetlight issues
- 🗑️ Garbage and waste management
- 🚰 Water and drainage problems
- 🏗️ Public infrastructure issues
- 🌳 Other local community concerns

The goal of the project is to provide a simple digital platform that connects citizens with civic issue management.

---

## 🚀 Features

### 📢 Issue Reporting

Citizens can report local civic problems by providing relevant information about the issue.

### 🏷️ Issue Categories

Reports can be organized into different categories, making it easier to identify and manage specific types of civic problems.

### 📍 Location-Based Reporting

The system can be used to identify the location associated with a reported civic issue.

### 📸 Issue Evidence

Users can provide supporting information or images related to the reported issue where applicable.

### 🔄 Status Tracking

Reported issues can be tracked through different stages of the resolution process.

Example statuses include:

- `Open`
- `In Progress`
- `Resolved`

### 👥 Community Feed

Users can view civic issues reported by other members of the community.

### 📱 Responsive Interface

The interface is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile devices

## 🛠️ Technologies Used

The project uses the following technologies:

- **HTML5** — Structure of the web application
- **CSS3** — Styling and layout
- **JavaScript** — Client-side functionality
- **Tailwind CSS** — UI styling
- **Python** — Backend/application support through `app.py`
- **SQLite** — Local database through `civicpulse.db`
